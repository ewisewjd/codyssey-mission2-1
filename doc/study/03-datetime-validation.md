# 03. 날짜와 입력 검증

## 공부할 개념
- 문자열 입력은 자동으로 날짜/숫자가 되지 않음
- `datetime.date.fromisoformat()` 또는 `datetime.strptime()`
- 날짜의 형식과 실제 유효성 차이
- YYYY-MM-DD와 YYYY-MM의 차이
- 금액을 정수로 변환할 때 발생하는 `ValueError`
- 허용 목록으로 값 검증하기
- 잘못된 입력을 거부하거나 다시 입력받는 정책

## 미션 적용
- 거래 날짜는 실제로 유효한 날짜여야 한다.
- 거래 금액은 양수 정수여야 한다.
- type은 income 또는 expense여야 한다.
- 월 필터는 YYYY-MM 형식이어야 한다.

## 확인 과제
`2026-02-30`, `2026-10-27`, `abc`, `0`, `-10`을 각각 검증하고 결과를 설명한다.
