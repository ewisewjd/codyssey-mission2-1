# 16. 테스트, 디버깅, 회귀 검증

## 공부할 개념
- 예상 결과와 실제 결과 비교
- 정상·오류·경계 테스트
- 빈 파일, 파일 없음, 잘못된 JSONL 행
- 테스트 데이터 분리
- 회귀 테스트: 새 기능을 추가한 뒤 이전 기능이 깨지지 않았는지 재확인
- 테스트 결과를 실제 증거와 함께 기록
- 실패한 테스트를 무시하지 않고 원인을 수정

## 각 기능의 최소 테스트
1. 정상 입력
2. 잘못된 입력 또는 없는 대상
3. 경계 조건 또는 빈 데이터
4. 재실행 후 데이터 유지
5. 관련 기존 기능 회귀 확인

## 미션 최종 4회 검토
1. 요구사항과 파일/함수 연결
2. 명령어와 정상 경로 실행
3. 오류·경계·영속성 확인
4. 전체 회귀·README·평가 시연 대조

## 확인 과제
검토마다 실행 명령, 실제 출력, 통과/실패, 수정한 파일을 기록한다. 실행하지 않은 항목은 통과로 표시하지 않는다.
