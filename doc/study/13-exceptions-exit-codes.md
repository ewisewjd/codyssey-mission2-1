# 13. 예외 처리와 종료 코드

## 공부할 개념
- 예외와 traceback의 의미
- `try`, `except`, `else`, `finally`
- `ValueError`, `OSError`, JSON 디코딩 오류
- 오류를 너무 넓게 잡아 숨기는 문제
- 사용자용 오류 메시지와 개발용 디버깅 정보의 차이
- `sys.exit()`와 종료 코드

## 미션 적용
잘못된 날짜, 금액, 카테고리, 파일 경로, CSV 행, 존재하지 않는 ID를 안전하게 처리한다. 오류 메시지에는 원인과 가능한 해결 힌트를 제공한다.

## 확인 과제
정상 명령은 종료 코드 0, 잘못된 옵션/파일 오류는 0이 아닌 종료 코드인지 확인한다.
