# 08. 제너레이터와 스트리밍

## 핵심 개념
일반적인 리스트는 모든 결과를 메모리에 모을 수 있다. 제너레이터는 `yield`로 값을 하나씩 제공하므로 전체 목록을 한꺼번에 만들지 않고 처리할 수 있다.

## 작은 예제
```python
def numbers():
    for number in range(3):
        yield number

for number in numbers():
    print(number)
```

## 미션 적용
- 거래 JSONL 파일을 한 줄씩 읽는 함수
- list와 search에서 제너레이터 기반 흐름 유지
- 수정·삭제처럼 전체 파일을 다시 써야 하는 작업과 읽기 스트리밍을 구분

## 주의
최신순 정렬은 전체 정렬을 위해 메모리에 데이터를 모아야 할 수 있다. 미션의 최신순 요구와 스트리밍 요구 사이의 구현 절충을 코드와 설계 문서에 명시하고, 실제 메모리 동작을 과장하지 않는다.

## 확인 과제
`yield`를 `return`으로 바꾸면 반복 결과가 어떻게 달라지는지 실행해 설명한다.
