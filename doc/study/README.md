## 각 문서를 공부하는 방법

1. 정의를 읽고 예제 코드를 직접 타이핑한다.
2. 값을 하나 바꿔 실행 결과를 예측한다.
3. `budget_app/`에서 같은 개념을 찾는다.
4. 정상·오류·경계 입력을 테스트한다.
5. 코드를 보지 않고 “무엇을, 왜, 어떻게 하는지” 말로 설명한다.

## 완료 기준

- [ ] 개념을 쉬운 말로 설명할 수 있다.
- [ ] 예제를 직접 실행하고 결과를 설명할 수 있다.
- [ ] 실제 코드 위치를 찾을 수 있다.
- [ ] 정상·오류·경계 사례를 테스트할 수 있다.
- [ ] 진행 상태를 `../CONCEPT_CHECKLIST.md`와 `../PROGRESS.md`에 반영한다.

사용자 설명과 실제 실행 절차는 [../user-guide/README.md](../user-guide/README.md)를 참고한다.
