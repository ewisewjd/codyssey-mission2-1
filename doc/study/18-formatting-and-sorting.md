# 18. 콘솔 출력 포맷과 정렬

## 상태
이 주제는 미션의 가독성 개선과 관련되며, 화려한 출력은 보너스에 가깝다.

## 공부할 개념
- f-string 폭 지정과 정렬
- 열 너비 맞추기
- 긴 메모 자르기/줄바꿈 정책
- `sorted()`와 키 함수
- 출력 형식과 실제 데이터 로직 분리

## 우선순위
필수 기능이 검증되기 전에는 출력 미관에 과도한 시간을 쓰지 않는다. 단, 최신순 정렬처럼 요구사항에 명시된 정렬은 필수다.

## 확인 과제
짧은 값·긴 값·한글 카테고리·빈 메모가 섞여도 표가 읽기 쉬운지 확인한다.
