# 12. 데코레이터

## 핵심 개념
데코레이터는 함수를 다른 함수로 감싸 공통 동작을 추가하는 문법이다. 예: 실행 시간 측정, 로그, 공통 예외 처리.

## 공부할 개념
- 함수도 값으로 전달할 수 있다는 점
- 내부 함수와 클로저의 기초
- `@decorator_name` 문법
- `functools.wraps`
- 인수와 반환값을 유지하는 래퍼 함수
- 데코레이터가 원래 기능을 바꾸지 않도록 주의

## 미션 적용
최소 하나를 정의하는 데 그치지 않고 실제 명령 처리 함수 또는 서비스 함수에 적용한다.

## 확인 과제
데코레이터가 적용된 함수의 실행 전후에 로그가 나타나는지 실행하고, 감싼 함수의 이름과 반환값이 보존되는지 확인한다.
