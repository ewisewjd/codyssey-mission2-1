# 11. 검색, 정렬, 집계

## 공부할 개념
- 조건 결합: AND로 필터들을 함께 적용
- 날짜 범위의 시작/끝 포함 여부를 명확히 하기
- 문자열 검색과 대소문자 처리 정책
- 태그 검색
- 최신순 정렬과 정렬 키
- 수입·지출 합계
- 카테고리별 합계와 TOP N
- 예산 사용률 계산: 지출 / 예산 × 100
- 예산 0 또는 미설정일 때의 처리

## 미션 적용
`search --from --to --category --type --q --tag`, `summary --month --top`

## 확인 과제
가짜 거래 5건으로 날짜·유형·카테고리·메모·태그 필터를 각각 테스트하고, 두 필터를 결합한 결과도 검증한다.
