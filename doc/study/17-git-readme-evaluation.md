# 17. Git, README, 평가 시연

## 공부할 개념
- working tree, staging area, commit
- `git status`, `git diff`, `git add`, `git commit`, `git log`
- 작고 의미 있는 커밋
- `.gitignore`와 개인 데이터 제외
- README의 실행 방법과 명령 예시
- CSV 스키마와 저장 위치 문서화
- 평가 시연의 재현 가능한 순서

## 미션 적용
- 실제 변경 이력을 남긴다.
- `data/`의 개인 거래 기록은 저장소에 올리지 않는다.
- README 예시는 실제 CLI 동작과 일치해야 한다.
- 평가 전에 새 데이터 디렉터리로 처음 실행하는 시나리오를 재현한다.

## 확인 과제
README만 읽은 사람이 추가 작업 없이 실행 방법과 각 명령을 이해할 수 있는지 확인한다.
