# 06. 파일과 경로

## 공부할 개념
- 상대 경로와 절대 경로
- 현재 작업 디렉터리와 실행 위치의 차이
- `pathlib.Path`
- `Path.mkdir()`, `exists()`, `open()`
- `with open(...)`으로 파일을 안전하게 열고 닫기
- UTF-8 인코딩
- 파일 읽기 모드 `r`, 쓰기 모드 `w`, 추가 모드 `a`
- 파일이 없거나 권한이 없을 때의 처리

## 미션 적용
- 기본 데이터 경로는 `./data`
- `--data-dir`로 저장 위치를 변경
- 첫 실행에서 데이터 파일이 없어도 프로그램이 동작
- 사용자 데이터 파일을 공개 Git 저장소에 커밋하지 않기

## 확인 과제
임시 디렉터리에서 파일을 만들고 읽고, 프로그램을 다시 실행해 내용이 남는지 확인한다.
