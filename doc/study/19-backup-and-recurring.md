# 19. 보너스: 백업과 반복 거래

이 문서는 필수 기능 완료 후에만 진행한다.

## 백업
- 타임스탬프를 포함한 백업 파일명
- 데이터 파일 세트의 일관성
- 백업이 실제로 생성됐는지 확인
- 복원 절차와 복원 전 원본 보존
- 민감한 거래 데이터의 공개 저장소 업로드 금지

## 반복 거래
- 월급·월세 규칙과 생성 대상 월
- 동일 월 중복 생성 방지
- 월말 날짜(예: 31일이 없는 달)
- 생성된 거래의 출처/규칙 추적 여부

## 확인 과제
필수 요구사항이 모두 검증된 뒤 백업 생성/복원 또는 반복 거래 중 하나를 선택한다.
